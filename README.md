# Ismail Hossain (AliF)

This repo is the source code for my personal portfolio site.

Before you peek under the hood, go check out the live version—you'll notice it looks a bit... unhinged. I built it in a comical sketch style (hand-drawn doodles, bold outlines, a little chaos) because I wanted it to be actually fun to browse. No boring gradients, no cookie-cutter corporate layouts. I wanted my work and my info to stand out while giving visitors a laugh (or at least a smirk) as they scroll.

It’s unique, it’s a little weird, and it’s 100% me.
